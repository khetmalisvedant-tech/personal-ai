# 🎓 Personal AI – Voice AI Tutor

An intelligent **Voice-enabled AI Tutor** that helps users learn any topic with:

* 📘 Detailed explanations
* 💡 Smart summaries
* 🧠 Practice questions
* 🎤 Voice input support
* 🔊 Audio responses

Built for fast, interactive, and multilingual learning (English, Hindi, Marathi).

---

## 🚀 Features

* 🎤 **Voice Input** – Ask questions using speech
* 🌐 **Multilingual Support** – English, Hindi, Marathi
* 📘 **AI Explanation Engine** – Clear and structured answers
* 💡 **Auto Summary** – Quick understanding of concepts
* 🧠 **Quiz Generation** – Practice what you learn
* 🔊 **Audio Output** – Listen to explanations
* ⚡ **Real-time UI** – Clean and responsive interface

---

## 🛠️ Tech Stack

### Frontend

* React (Vite)
* JavaScript (ES6+)
* CSS (Custom UI)

### Backend

* FastAPI (Python)
* AI Engine (LLM / Ollama / OpenAI)
* Speech & Audio Processing

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository

```bash
git clone https://github.com/khetmalisvedant-tech/personal-ai.git
cd personal-ai
```

---

### 2️⃣ Backend Setup

```bash
cd backend
pip install -r requirements.txt
uvicorn app:app --reload
```

Backend runs on:

```
http://localhost:8000
```

---

### 3️⃣ Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

Frontend runs on:

```
http://localhost:5173
```

---

## 🧠 How It Works

1. User enters or speaks a question
2. Language is automatically detected
3. Backend processes request using AI engine
4. Generates:

   * Explanation
   * Summary
   * Quiz
   * (Optional) Audio
5. Response is displayed in UI
